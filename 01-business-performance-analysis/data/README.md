# Data

This folder contains the datasets used in the Business Performance Analysis project.

## Files

The dataset is generated using the Python script:

`python/generate_sample_data.py`

The generated datasets include:

- customers.csv
- products.csv
- regions.csv
- dates.csv
- sales.csv

## Dataset Overview

The synthetic dataset represents business transactions across Germany and includes:

- 200 customers
- 8 products
- 4 business regions
- Daily calendar data from 2024 to 2026
- 5,000 sales transactions
- Revenue
- Cost
- Profit
- Discounts
- Customer segments
- Product categories
- Geographic information

## Purpose

The data is designed for practicing and demonstrating:

- SQL analysis
- Power BI reporting
- DAX
- Data modeling
- ETL
- KPI analysis
- Business intelligence
- Exploratory data analysis

## Note

All data used in this project is synthetic and does not contain real customer or company information.
