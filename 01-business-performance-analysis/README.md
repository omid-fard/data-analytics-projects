# Business Performance Analysis

This project analyzes business performance using SQL, Power BI, DAX, and data modeling techniques.

The objective is to transform raw business data into meaningful KPIs, trends, and management insights.

## Project Objectives

- Analyze overall business performance
- Monitor revenue and profitability
- Identify top-performing products and categories
- Compare regional performance
- Analyze customer behavior
- Track monthly and yearly trends
- Build management KPIs
- Develop an interactive Power BI dashboard
